+ (Suggestion.) Functors describe what the program is; tables/maps describe compiler state and extensible metadata.

I would use a hybrid

Keep semantic AST structure as functors, but don't turn every compiler fact into another positional argument.

For example:

Binary("+", A, B)

plus either a modest common wrapper:

At(Position, Binary("+", A, B))

or an annotation structure:

Node(Binary("+", A, B), Meta)

where Meta can be a table if needed.
